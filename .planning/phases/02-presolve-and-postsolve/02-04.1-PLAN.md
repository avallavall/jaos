<objective>
Fifteen answers on the standard set and four on Kennington are refused by the
checker on its dual sign condition. Find out why, on the diff that caused it,
before two more reduction families are built on top of the same replay.

Purpose: the fall is not spread across the phase. Three campaigns against the
same baseline and the same 94 instances put all of it inside one plan's diff:

| tree | checker ok | rejected |
|---|---|---|
| `03c28c9` — end of 02-02 | 93 | 1 (`finnis`, D24, documented) |
| `8425acc` — end of 02-03 | 78 | 16 |
| `d861b22` — end of 02-04 | 79 | 15 |

02-03 verified only the infeasible set and said so in its own summary, so
fifteen rejections crossed a whole wave unseen. 02-04 found and fixed one of
them by accident — its fifth deviation rewrote the singleton row's dual
recovery because a status-based discriminator had stopped being able to
answer — which is evidence that the rest are the same class and reachable.

Every one of the 94 objectives matches Koch's reference and all 94 are
deterministic. The primal side of the answer is right. What is wrong is the
multiplier postsolve publishes beside it, and that is the defect class the
phase boundary named as the real risk.

This plan does not run a campaign to decide anything. It reads a diff of known
size, instruments one instance, and names a site. 02-06 still reviews the whole
phase diff before 02-07's campaigns; this is the narrower question asked
earlier, because 02-05 would otherwise add two families to a replay nobody has
looked at.
</objective>
