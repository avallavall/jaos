<objective>
Prove the change is an observable no-op on all 139 published answers, then —
and only then — rewrite the three work baselines to describe the accounting
plan `01-02` established.

Purpose: this phase is designed to leave every trajectory exactly where it was.
D-05 makes that a hard acceptance criterion rather than a hope: the candidate
set, the array positions and therefore every tie-break are unchanged by
construction, so a moved digest means the change touched something it should
not have. And the work counts have deliberately moved, which means the
baselines no longer describe the solver — but the order in which those two
facts are established is load-bearing. Digests first, rewrite second. Doing it
the other way round fills the per-instance diff with noise and destroys the
only instrument that can report a regression at all (D-06).

Output: three campaign records with 139 unmoved digests, three rewritten
baselines, and a confirming gate run that diffs clean against them.
</objective>
