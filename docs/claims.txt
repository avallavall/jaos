# Claims of absence, checked by `make record-check` (tools/record-check.py).
#
# Each line: absent <where the record makes the claim> <regex>
#
# The regex must NOT match any source file (src/, include/, bench/*.c,
# tests/, Makefile) with comments stripped. When it does, the thing the record
# says is missing has been built, and the row named in the second column is
# the one that has to change in the same commit. That is the whole mechanism:
# a claim of absence is true the day it is written and silently false the day
# the feature lands, and nothing else in the tree notices.
#
# Patterns are symbol-shaped on purpose. Prose cannot trigger them because
# comments are stripped before matching.
